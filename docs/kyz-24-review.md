## Общая проверка

Все 24 адреса страниц шаблонов ответили HTTP 200. Каждый рендерит обложку, семь внутренних разделов и RSVP; у изображений нет ошибок загрузки. Ширина desktop соответствует PNG образца, мобильная ширина — 390 px. Горизонтальное переполнение равно 0 px на обеих ширинах для всех шаблонов. Ошибок выполнения JavaScript на страницах нет.

Проверен путь в production: карточка шаблона → кнопка «Чакырууну көрүү» → кнопка «Чакырууну ачуу» → форма RSVP. Форма подтвердила демо-ответ и показала сообщение, не отправляя гостевые данные на сервер. Кнопка карты и кыргызский текст присутствуют. Идентификаторы в каталоге оставлены прежними.


### Заменённые материалы

Фотографии подобраны из локальных WebP в public/images/template-restored/, включая kyz-burgundy-bride.webp, kyz-gold-bride-hero.webp, kyz-gold-bride-footer.webp, kyz-burgundy-hat.webp и kyz-ethno-hero.webp. Оригинальные фото из примеров не были предоставлены как отдельные файлы. Атласные волны, цветочные гирлянды и рамки собраны из доступных локальных изображений, SVG-мотивов и CSS-форм. Использованы имеющиеся шрифты Great Vibes, Marck Script и Cormorant Garamond; редкие кыргызские буквы отображаются запасным шрифтом.
