# Свадебные шаблоны из архива

## Устройство

- `lib/referenceWeddings.ts`: каталог, исходные цвета, имена, даты и координаты фотографий в референсах.
- `components/ReferenceWedding.tsx` и `.module.css`: девять вариантов композиции и общие интерактивные блоки.
- `WeddingEditor` / `WeddingPart`: выбор, перемещение, изменение текста и замена фотографий через основной редактор. Дополнительной панели внутри приглашения нет.
- `canvas.copy["reference.design"]`: сохраняет вид шаблона при клонировании в админке.
- `public/images/wedding-references`: локальные источники фотографий и декоративных фрагментов. CSS показывает только нужный фрагмент; загруженная пользователем фотография заменяет его.
- Форма использует существующий RSVP API. Дополнительные поля `Guest.drinks` и `Guest.note` сохраняют предпочтения и пожелания. В предпросмотре данные не отправляются.

Сохраняются исходные даты макетов; для прошедших мероприятий таймер показывает нули. Календарь и таймер обновляются при изменении даты.

## Проверки

```powershell
node node_modules/typescript/bin/tsc --noEmit
node node_modules/eslint/bin/eslint.js components/ReferenceWedding.tsx lib/referenceWeddings.ts scripts/verify-reference-weddings.mjs
node scripts/verify-reference-weddings.mjs --http
```

HTTP-проверка предполагает работающий dev-сервер на `http://localhost:3000`. Можно задать `PREVIEW_URL`. Проверяются девять маршрутов, серверный рендеринг, уникальность идентификаторов редактора, изображения, границы фрагментов, клонирование и сохранение полей RSVP через тестовую замену базы.

## Ограничения исходников

Часть референсов обрезана снизу; отсутствующие секции дополнены. Шрифты подобраны из установленных в проекте. Чёткость фрагментов ограничена разрешением JPG. Визуальное совпадение в браузере не подтверждено: инструмент Computer Use был остановлен автоматической проверкой безопасности из-за невозможности определить текущий URL.

Обложки `mountains-hero-clean.png` и `stars-hero-clean.png` восстановлены с помощью ImageGen по соответствующим скриншотам: старые надписи удалены, чтобы поверх фотографии можно было менять имена и дату. Это реконструкция фотографий, а не исходные файлы фотографа.
