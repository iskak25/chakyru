# Реестр шрифтов и проверка глифов (ТЗ §7.1)

Проверено 2026-10-29 через fontkit по файлам из `app/fonts/`: глифы ң Ң ө Ө ү Ү, ё Ё, № — « », кириллица А–я.
Все шрифты — Google Fonts, лицензия SIL OFL 1.1 (файл `OFL.txt` лежит рядом с каждым), источник
https://github.com/google/fonts/tree/main/ofl/<семейство>.
