# Тематические фотографии приглашений

Созданы через встроенный `image_gen` и сохранены в WebP (1024 × 1536, quality 92, без увеличения разрешения).

Краткое содержание заданий генерации:

- `beshik-nur`: резная кыргызская колыбель бешик, светлое вышитое бельё и зелёный текстиль, мягкий естественный свет, без людей и надписей.
- `balalyk`: улыбающийся ребёнок из Центральной Азии на детском празднике, голубой наряд, небольшой торт и пастельные воздушные шары, без надписей.
- `ak-jooluk`: взрослая невеста из Центральной Азии в белом шёлковом платке, светлом вышитом платье, с небольшим букетом, мягкий светлый интерьер.
- `kyz-uzatuu-photo`: взрослая невеста в традиционном бордовом бархатном наряде, вышитый головной убор, серебряные украшения и длинные косы, светлый фон с местом для текста.

Файлы: `public/images/templates/<id>/hero-themed.webp` для каждого из четырёх идентификаторов выше. Подключение: `lib/templatePhotos.ts`; пользовательское загруженное фото по-прежнему имеет приоритет.

Превью `minimal-white` и `pin-kyz-pearl` рисуются компонентом `TemplatePaperPreview`, используя бумагу, рамку, декор и данные соответствующего приглашения. `baxmal` использует `/images/hero.jpg`, как основной экран приглашения.
