# Ответы, пожелания и отправка ссылки

## Текущий интерфейс пожеланий

Поздравления отправляются через единую плавающую кнопку «КААЛОО / ПОЖЕЛАНИЕ» на `/i/[id]`. Она открывает модальное окно с именем и текстом. Черновик сохраняется при закрытии окна; после успешной записи показывается подтверждение в том же окне. Встроенные поля поздравлений и карусели пожеланий из шаблонов удалены. Поля RSVP и комментарии по меню сохранены. Таблица ниже описывает исходные обработчики аудита; поздравления из объединённых форм теперь перенесены в это окно. API объединённой отправки сохранён для совместимости.

## Куда поступают данные

- Ответы RSVP: `POST /api/invitations/[id]/rsvp` → Firestore `invitations/{id}.guests`.
- Поля ответа: `name`, `rsvp`, `plusOne` (дополнительные гости, без самого отвечающего), `drinks`, `note` (меню / комментарий).
- Поздравления: `POST /api/invitations/[id]/wish` → `invitations/{id}.wishes`.
- В объединённой форме текст `wish` отправляется вместе с RSVP и записывается в `wishes` той же транзакцией. Повтор идентичного объединённого ответа не дублирует поздравление.
- Владелец читает данные через `/responses`, используя авторизованный `GET /api/invitations`. Кнопки расположены на странице шаблона и в `/dashboard`.

## Проверенные обработчики

| Шаблоны / компонент | Что отправляется |
| --- | --- |
| Основной `WeddingInvitation` | Участие, число гостей, напитки, поздравление |
| `ReferenceWedding`: rose, silk, calligraphy, mountains, sage, burgundy, tuscany, winter, stars | Участие, число гостей; rose / tuscany — поздравление; rose — напитки |
| `PinterestInvite`: ethno, burgundy, goldBride, pearl, blue | Участие, вариант с парой |
| `FamilySiteInvite`: жентек и тушоо | Участие, число гостей, меню / комментарий |
| `ThemedSiteInvite`: silkSite, nikahSite, monoSite, newspaperSite, glam, blushParty | Участие; свадебные варианты — поздравление, девичник — меню |
| `AnniversaryInvite`: monochrome, evening | Участие, число гостей, меню / комментарий |
| Старые `Site3DLayouts`, `Site3DInviteLayouts`, общий `RsvpForm` | Участие, вариант с супругом сохраняется как `yes` + 1 гость |
| Семейства Elegant, Mauve, ToiAnket, Tuscany | Участие и поздравление; отдельное число гостей / напитки, где предусмотрены |
| `GuestWishForm`, окно пожеланий `Site3D` | Имя и поздравление |

Блоки с текстом от хозяев **«Пожелания гостям»**, правилами подарков или дресс-кодом — обычное содержимое приглашения, они ничего не отправляют.

## Подтверждение

`guestFetch` проверяет успешный HTTP-ответ и ID сохранённой записи. Только затем показывает общее модальное окно. При ошибке форма не очищается. Для demo / preview данные не отправляются. Редактор не отправляет гостевые формы.

## Ачык шилтеме

В редакторе открывается диалог: WhatsApp, Telegram, Facebook, копирование ссылки, системная отправка (если поддерживается браузером). Отправка выполняется самим пользователем в выбранном приложении.
Ссылка содержит `/i/{id}`, а не адрес редактора. Telegram: https://core.telegram.org/widgets/share; WhatsApp: https://faq.whatsapp.com/5913398998672934.

## Проверки

- `node scripts/verify-template-forms.cjs` — 23 варианта основных шаблонов, отправка, повтор после ошибки, изоляция preview / editor, супруг и поздравления.
- `node scripts/verify-anniversary-rsvp.mjs` — юбилейные формы.
- `node scripts/verify-guest-responses.cjs` — сохранение, транзакции, защита от старой копии, объединённая форма, пожелания.
- `node scripts/verify-guest-feedback.cjs` — подтверждения, ошибки, блокировка повторного клика, ссылки и буфер обмена.

Проверки выполняются с имитацией запросов и хранилища: тестовые ответы реальным владельцам не отправляются.
